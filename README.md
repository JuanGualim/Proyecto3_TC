# Proyecto 3 — Simulador de Máquinas de Turing

Curso: Teoría de la Computación

Integrantes:

- Juan Gualim
- Denil Parada
- Harry Méndez

Simulador de Máquinas de Turing (MT) de **una cinta**, escrito en **Rust**. Lee la
descripción formal de la máquina desde un archivo YAML, simula cada cadena de entrada,
muestra la secuencia completa de descripciones instantáneas (IDs) e indica si la cadena
es aceptada o rechazada.
